# Empresa de IA: Hotel Cabanas 🌿

Uma equipe de funcionários de IA para o Hotel Cabanas, em Bonito/MS, montada e gerida por uma **Diretora de RH de IA**.

## Como usar
1. Abra uma sessão do Claude Code com este repositório.
2. Digite **`/rh`** e peça, por exemplo:
   - "Faça o diagnóstico e me proponha as primeiras vagas."
   - "Quero contratar alguém para os anúncios no Instagram."
   - "Mostre o organograma."
3. O RH propõe a descrição da vaga e **você aprova**.
4. O RH cria o funcionário, testa no período de experiência e registra no organograma.
5. Depois é só pedir tarefas: o Claude delega ao funcionário certo.

## Para atualizar o contexto do hotel
Edite `contexto/hotel-cabanas.md` (ou adicione novos documentos em `contexto/`). Todos os funcionários passam a usar a versão nova automaticamente.
